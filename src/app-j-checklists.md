# Appendix J — Printable checklists

Print a list, tick each box as you go, and start again next time. Each list stands on its own.

## Your first chat

- [ ] Pick one assistant and open it.
- [ ] Make an account or sign in.
- [ ] Type one simple question.
- [ ] Read the answer and ask one follow-up.
- [ ] Ask it to make the answer shorter.
- [ ] Save the chat if the answer was useful.

## Before you share anything with AI

- [ ] No passwords in the message.
- [ ] No bank or card numbers.
- [ ] No ID numbers or addresses you would not share in public.
- [ ] No private health details.
- [ ] No work secrets in a personal account.
- [ ] Photos checked for names, schools, and street signs.

## Before you trust an answer

- [ ] Is this a fact or a guess?
- [ ] Does it name a source I can open?
- [ ] Have I checked the key facts somewhere else?
- [ ] Would a wrong answer cost me money, health, or safety?
- [ ] If yes, I have checked it with a trusted source.

## Setting up a new assistant

- [ ] Pick the assistant for this job.
- [ ] Sign in with the right account.
- [ ] Check the plan and its limits.
- [ ] Turn on the privacy settings I want.
- [ ] Try one small job before a big one.
- [ ] Save one good prompt to reuse.

## Starting a new project with AI

- [ ] Write down what "done" looks like, in one sentence.
- [ ] List the facts the AI needs.
- [ ] Pick the tool for the job.
- [ ] Break the job into small steps.
- [ ] Do step one and check the result.
- [ ] Save your work before you go on.

## Before you publish anything AI helped with

- [ ] Read every word yourself.
- [ ] Check names, dates, and numbers.
- [ ] Check the tone sounds like you.
- [ ] Remove anything you would not say yourself.
- [ ] Check the source of any quote or fact.
- [ ] Add your own view, not just the AI's words.

## Keeping costs down

- [ ] I know which plan I am on.
- [ ] I know what my plan costs each month.
- [ ] I have turned off tools I do not use.
- [ ] I use a cheaper model for simple jobs.
- [ ] I have set a spending cap if the tool offers one.
- [ ] I checked the current price before renewing.

## Backing up your work

- [ ] My notes are saved in more than one place.
- [ ] My code is saved with Git and pushed to GitHub.
- [ ] My automations are exported or written down.
- [ ] I know where the backup lives.
- [ ] I tested opening the backup once.

## Going live with an automation

- [ ] I tested it by hand, end to end.
- [ ] I tested it with bad input, not just good input.
- [ ] I know what it does when it fails.
- [ ] I know how to turn it off fast.
- [ ] Someone else could read the steps and follow them.
- [ ] I checked the schedule and the time zone.

## Teaching someone else about AI

- [ ] I picked one small win to show them first.
- [ ] I used plain words, no jargon.
- [ ] I let them type the prompt themselves.
- [ ] I showed them how to spot a wrong answer.
- [ ] I showed them what never to share.
- [ ] I left them with one prompt to try alone.

## Your first month, week by week

- [ ] Week 1: I had my first chats and saved one good prompt.
- [ ] Week 2: I used AI for one real work job.
- [ ] Week 3: I built one small automation or project.
- [ ] Week 4: I taught one trick to someone else.
- [ ] I know which assistant I like best, and why.
- [ ] I know what I want to learn next.
