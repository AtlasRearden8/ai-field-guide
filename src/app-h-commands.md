# Appendix H — Commands and shortcuts

The keys and commands you will actually use. On a Mac, use Cmd where this list says Ctrl.

## Everyday keyboard shortcuts

| Keys | What it does |
| --- | --- |
| Ctrl + C | Copy the selected text. |
| Ctrl + V | Paste what you copied. |
| Ctrl + X | Cut the selected text. |
| Ctrl + Z | Undo the last change. |
| Ctrl + A | Select everything on the page. |
| Ctrl + F | Find a word on the page. |
| Ctrl + S | Save your work. |
| Ctrl + N | Open a new window or chat. |
| Ctrl + Enter | Send a message in most chat apps. |
| Shift + Enter | Add a new line without sending. |
| Esc | Close a menu or stop what is running. |

## In a chatbot

- Start a new chat for a new topic. Old chats steer the answers.
- Press Shift + Enter for a new line inside one message.
- Use the microphone button to talk instead of typing.
- Use the paperclip or plus button to add a file or photo.
- Use the thumbs up or down to tell the tool if an answer helped.

## In the terminal (Mac and Linux)

| Command | What it does |
| --- | --- |
| pwd | Show which folder you are in. |
| ls | List the files in this folder. |
| cd folder-name | Move into a folder. |
| cd .. | Move up one folder. |
| mkdir name | Make a new folder. |
| cp file copy | Copy a file. |
| mv old new | Move or rename a file. |
| rm file | Delete a file. Be careful, there is no undo. |
| clear | Clear the screen. |
| Ctrl + C | Stop the running command. |

## Git: saving your work

| Command | What it does |
| --- | --- |
| git init | Start tracking a folder. |
| git status | Show what has changed. |
| git add . | Stage all changes to save. |
| git commit -m "message" | Save the staged changes with a note. |
| git log | Show past saves. |
| git push | Send your saves to GitHub. |
| git pull | Bring in the latest saves from GitHub. |
| git branch name | Make a new branch to try an idea safely. |

## Ollama: local AI

| Command | What it does |
| --- | --- |
| ollama list | Show the models on your machine. |
| ollama pull model-name | Download a model. |
| ollama run model-name | Start chatting with a model. |
| ollama rm model-name | Remove a model to free space. |

## Docker: the basics

| Command | What it does |
| --- | --- |
| docker ps | Show the apps that are running. |
| docker stop name | Stop a running app. |
| docker start name | Start a stopped app. |
| docker logs name | Show what an app has been doing. |

## n8n: the basics

- Click a node to open its settings.
- Drag from one node to the next to join them.
- Press "Execute step" to test one node at a time.
- Press "Execute workflow" to test the whole flow.
- Turn a workflow on with the Active switch at the top right.
- Check the Executions tab to see past runs and errors.

## Markdown: the writing marks in this book

| Mark | What it does |
| --- | --- |
| # Title | A big heading. |
| ## Heading | A smaller heading. |
| **bold** | Bold text. |
| *italic* | Italic text. |
| - item | A bullet point. |
| 1. item | A numbered list item. |
| - [ ] item | A checklist box you can tick. |
| `code` | Text shown exactly as typed, for code. |

## If a command fails

- Read the error out loud. It often names the problem.
- Check for a typo, especially in names and paths.
- Copy the error into your assistant and ask for a plain-words fix.
- Try the command again after fixing one thing, not five.
